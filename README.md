
# High-Concurrency Flash-Sale E-Commerce Engine

Homework 3 - Vietnam Flash Sale Simulation

## Project Overview

A Flash Sale E-Commerce simulation built using
React and TypeScript.

The project focuses on:
- Zero-drift countdown timer
- Inventory reservation state machine
- High-concurrency scenarios
- Checkout flow
- AI failure mode audit

## Tech Stack

- React
- TypeScript
- Vite
- CSS

## Getting Started

### Prerequisites

- Node.js compatible with the installed Vite version
- npm
- Git

### Installation

npm install

### Development

npm run dev

### Production Build

npm run build

### Preview

npm run preview
